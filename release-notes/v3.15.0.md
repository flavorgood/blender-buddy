# Blender Buddy v3.15.0 — animation's eighth piece: growing

One new guided flow, and nothing else changes.

**Make it grow** sits under "Learn by doing" beside the
modeling, sculpting and first seven animation pieces —
Buddy's eighth animation piece, teaching growing, in
four steps:

1. **Pick the thing that will grow** — one thing whose
   size will change.
2. **Remember its starting size** — a scale memory at
   frame 1, holding today's size so a later size has
   something to grow from.
3. **Grow it a clear amount and remember again** — the
   size multiplied (the reference build: two and a
   half times) and remembered at frame 48.
4. **Watch it grow, then save it** — played across the
   span, and the file saved with both size memories
   in it.

The teaching point is that the memories can hold a
thing's SIZE, not only its place: a seed sprouting, a
balloon filling, a creature rearing up — two size
memories, and Blender fills in every size between.
The checks read the size memories themselves and the
real evaluated size at their frames: the span must
run at least 20 frames and the size must really
multiply — at least 1.8 times (the reference build's
ratio is 2.5, reading 1.73 halfway at frame 24). A
probe on Blender 5.3.0 and 4.2.5 before building
showed size memories read back and interpolate
identically on both versions.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a starting size alone
does not prove the grow, and a small nudge of size
(1.2 times) does not prove it either.

Verified on Blender 5.3.0 AND 4.2.5 at the final
v3.15.0 source: the flows battery (all sixteen flows
plus the anim_scale negatives), the interface battery,
and the plain-layer and search batteries all pass on
both versions. Proof picture: demo/anim_scale_final.png
— the reference build's red thing at frame 48,
full-grown at two and a half times its starting size,
on the ground.
