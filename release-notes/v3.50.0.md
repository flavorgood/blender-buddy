# Blender Buddy v3.50.0 — animation's forty-third piece: stepping back

One new guided flow, and nothing else changes. Built and
held locally under the owner's 2026-11-26 release-batching
rule — this is batch bookkeeping, not a separate release;
it ships together with the first batched release.

**Make it step back** sits under "Learn by doing" beside the
modeling, sculpting and first forty-two animation
pieces — Buddy's forty-third animation piece, teaching
stepping back, in four steps:

1. **Pick the thing that will step back** — one thing that will
   step backward and stay there.
2. **Remember where it starts, on the ground** — a place
   memory at frame 1, its centre no more than 1.3 units up.
3. **Step it back and keep it there** —
   moved backward 2.0 units along X remembered at frame 24, and
   the same stepped-back place remembered again at frame 48, at
   the same ground height the whole way.
4. **Watch it step back, then save** — played across the
   span, and the file saved with the place memories
   in it.

The teaching point is that a step back is the backward
step and the staying together: the slide piece sent a thing
travelling forward along the ground, and the sidestep piece
stepped a thing sideways and kept it there — a step back
steps backward, along the X axis toward negative X, and stays in the
new place, on the ground the whole way, never travelling
sideways and never leaving the ground, reading places
(0, 0, 0) / (-2, 0, 0) / (-2, 0, 0) at frames
1/24/48 in the reference build (-0.9348 backward partway
across at frame 12). The checks sample the real evaluated place
across the span: the span must run at least 20 frames,
the backward displacement from the start place to the end
place must land between 1.7 and 2.3 (the end place's X
minus the start place's X between -2.3 and -1.7), the sideways drift
along Y must stay within 0.5 across all samples, the end
height must land within 0.3 of the start height, and the
total sampled height range must stay within 0.35. A probe on Blender 5.3.0 and 4.2.5
before building showed the place memories at
(0, 0, 0), (-2, 0, 0) and (-2, 0, 0) across frames
1/24/48 read back and interpolate identically on both
versions (span 47, backward 2.0, sideways drift
0.0, start 0.0, end 0.0, height range 0.0 in the probe); a forward slide read backward -3.0,
a sidestep read backward 0.0 with sideways drift 2.0, a pace read backward 0.0 ending
home, a small step back read backward 0.5, a diagonal step
back read backward 2.0 with sideways drift 2.0, and a hop read
height range 1.5 — all failing the bar.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a ground starting
place alone does not prove the step back, a forward slide does not
prove it, a sidestep does not prove it, a pace does not prove it, a small step back does not
prove it, a diagonal step back does not prove it, and a hop
does not prove it either.

Verified on Blender 5.3.0 and 4.2.5 at the final
v3.50.0 source: the flows battery (all fifty-one
flows plus the anim_backstep negatives), the interface
battery, and the plain-layer and search batteries all
pass. Proof picture: demo/anim_backstep_final.png — the
reference build's red thing at frame 36, in its
stepped-back place on the ground with its
shadow below.
