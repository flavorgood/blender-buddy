## Buddy Expert

- Open or reopen the floating conversation from **Open Buddy Expert** in the Blender Buddy sidebar. Submit a request with **Enter** or **Ask**. Other sidebar tools stay available.
- Use the Expert from a new, unsaved project. **Expert help with tasks** starts on and remembers your choice across launches. Read the proposed steps and press **Run these steps** when you want to apply them.
- Ask for a flat circle on a selected mesh to add a removable modifier. The original mesh stays available.
- ChatGPT login on Windows handles Codex desktop installations and long scene descriptions. Requests have a time limit, and you can press **Esc** in the 3D Viewport to stop waiting.
- If you switch scenes or change the selection before running a reviewed plan, Buddy asks for a new request. Expert plans exclude delete, save and export actions. Remote requests follow Blender’s online-access preference.

## Update an existing installation

Download **blender_buddy_v3.2.4_extension.zip** for an existing extension. In Blender, open **Edit → Preferences → Get Extensions**, use the upper-right menu, choose **Install from Disk**, then select the ZIP and the same local repository. Check for version **3.2.4** in Preferences.

For a classic add-on installation, use **blender_buddy_v3.2.4.zip** from the same release through the Add-ons installation control.

If you have a scene open or an Expert request in progress, you can leave that process open and start a second Blender process for the update. The open process continues using the version it loaded.
