# Blender Buddy v3.19.0 — animation's twelfth piece: fading

One new guided flow, and nothing else changes.

**Make it fade** sits under "Learn by doing" beside the
modeling, sculpting and first eleven animation pieces —
Buddy's twelfth animation piece, teaching fading, in
four steps:

1. **Pick the thing that will fade** — one thing that
   will melt away.
2. **Remember it solid** — a fade memory at frame 1 on
   the paint's Alpha slot, fully there at 1.0, the
   reference build wearing red with its paint set to
   blend so the see-through amount shows.
3. **Fade it, and remember again** — mostly gone (0.1)
   remembered at frame 48.
4. **Watch it fade, then save it** — played across the
   span, and the file saved with both fade memories
   in it.

The teaching point is that the memories can hold how
THERE a thing is as a journey of its own: solid, mostly
gone, and Blender blending between them — halfway, at
frame 24, it reads 0.564, a little more than half there.
The fade memories live on the material's node tree and
are read through the same cross-version helper as every
other memory. The checks read the memories themselves
and the real evaluated see-through amount at the first
and last memories: the span must run at least 20 frames,
it must start solid (at least 0.9) and end mostly gone
(at most 0.35). A probe on Blender 5.3.0 and 4.2.5
before building showed the Alpha slot is inputs[4] of
the standard surface on both versions, and a solid
memory at frame 1 and a 0.1 memory at frame 48 read
back and blend identically on both versions.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a solid start alone
does not prove the fade, and a slight dimming does not
prove it either.

Verified on Blender 5.3.0 AND 4.2.5 at the final v3.19.0
source: the flows battery (all twenty flows plus the
anim_fade negatives), the interface battery, and the
plain-layer and search batteries all pass on both
versions. Proof picture: demo/anim_fade_final.png —
the reference build's thing at frame 48, faded to a
ghost of red at the end of its melt from solid, on
the ground.
