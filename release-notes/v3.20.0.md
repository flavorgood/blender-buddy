# Blender Buddy v3.20.0 — animation's thirteenth piece: pulsing

One new guided flow, and nothing else changes.

**Make it pulse** sits under "Learn by doing" beside the
modeling, sculpting and first twelve animation pieces —
Buddy's thirteenth animation piece, teaching pulsing, in
four steps:

1. **Pick the thing that will pulse** — one thing whose
   size will swell and settle.
2. **Remember its starting size** — a size memory at
   frame 1, the home size the pulse returns to.
3. **Swell it, then settle it back** — 2.5 times the
   size remembered at frame 24, the starting size
   remembered again at frame 48.
4. **Watch it pulse, then save it** — played across the
   span, and the file saved with all three size memories
   in it.

The teaching point is that a size journey can come
home: home, swollen, home again, and Blender filling in
the swell and the settle between them — a quarter of
the way across, at frame 12, it reads 1.701 times the
starting size. The checks read the size memories
themselves and the real evaluated size sampled across
the whole span: it must run at least 20 frames, the
peak must really multiply (at least 1.8 times the
start), and the ends must sit back together (within
0.3 of the starting size). A probe on Blender 5.3.0
and 4.2.5 before building showed size memories at 1.0,
2.5 and 1.0 across frames 1/24/48 read back and
interpolate identically on both versions.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a starting size alone
does not prove the pulse, a grow that never settles
does not prove it either, and a small swell does not
prove it.

Verified on Blender 5.3.0 AND 4.2.5 at the final v3.20.0
source: the flows battery (all twenty-one flows plus
the anim_pulse negatives), the interface battery, and
the plain-layer and search batteries all pass on both
versions. Proof picture: demo/anim_pulse_final.png —
the reference build's red thing at frame 24, at the
top of its pulse at 2.5 times its starting size, on
the ground.
