# Blender Buddy v3.55.0 — animation's forty-eighth piece: standing up

One new guided flow, and nothing else changes. Built and
held locally under the owner's 2026-11-26 release-batching
rule — this is batch bookkeeping, not a separate release;
it ships together with the first batched release.

**Make it stand up** sits under "Learn by doing" beside the
modeling, sculpting and first forty-seven animation
pieces — Buddy's forty-eighth animation piece, teaching
standing up, in four steps:

1. **Pick the thing that will stand up** — one thing that will
   rise from crouched down and stay standing.
2. **Remember its starting size, crouched down** — a size
   memory at frame 1, crouched down, i.e. scale (1, 1, 0.5).
3. **Stand it up and keep it standing** —
   full height (Z scale 1.0) remembered at frame 24, i.e. (1, 1, 1), and
   the same full size remembered again at frame 48, sides
   staying at 1.0 the whole way.
4. **Watch it stand up, then save** — played across the
   span, and the file saved with the size memories
   in it.

The teaching point is that a stand-up is the rising
and the staying and the unchanged sides together: the crouch piece
lowered a thing down while its sides stayed at their own size and then kept it lowered — a stand-up
starts crouched, raises the height only to full, and stays in the
standing size, its sides never changing, reading sizes
(1, 1, 0.5) / (1, 1, 1) / (1, 1, 1) at frames
1/24/48 in the reference build ((1, 1, 1) again at frame 36). The checks sample the real evaluated size
across the span: the span must run at least 20 frames,
the start height ratio (start Z over end Z) must land between 0.35 and 0.65, the end height ratio (end Z against a full height of 1.0) must land between 0.85 and 1.15, the end
side ratios (X and Y) must each land between 0.8 and 1.2, and the
sampled height ratio must never fall below 0.35 or rise above 1.15. A probe on Blender 5.3.0 and 4.2.5
before building showed the size memories at
(1, 1, 0.5), (1, 1, 1) and (1, 1, 1) across frames
1/24/48 read back and interpolate identically on both
versions (span 47, start height 0.5, end height 1.0, end sides
1.0 and 1.0, lowest 0.5, highest 1.0 in the probe); a crouch read start height 2.0 with end height 0.5,
a squash read start height 1.0, a shrink read end sides 0.4 and 0.4, a stretch read end height 2.0 with lowest 0.25, a small stand read start height 0.85, and a stand that crouched back
read end height 0.5 — all failing the bar.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a crouched starting
size alone does not prove the stand-up, a crouch does not
prove it, a squash does not prove it, a shrink does not prove it, a stretch does not prove it, a small stand does not
prove it, and a stand that crouches back does not prove it either.

Verified on Blender 5.3.0 and 4.2.5 at the final
v3.55.0 source: the flows battery (all fifty-six
flows plus the anim_standup negatives), the interface
battery, and the plain-layer and search batteries all
pass. Proof picture: demo/anim_standup_final.png — the
reference build's red thing at frame 36, standing
at full height with its sides unchanged, on the
ground.
