# Blender Buddy v3.27.0 — animation's twentieth piece: shrinking

One new guided flow, and nothing else changes. Built and
held locally under the owner's 2026-11-26 release-batching
rule — this is batch bookkeeping, not a separate release;
it ships together with the first batched release.

**Make it shrink** sits under "Learn by doing" beside the
modeling, sculpting and first nineteen animation pieces —
Buddy's twentieth animation piece, teaching shrinking, in
four steps:

1. **Pick the thing that will shrink** — one thing whose
   size will fall.
2. **Remember its starting size** — a size memory at
   frame 1 at full size.
3. **Shrink it small and remember again** — every side
   down to 0.4 of its start, remembered at frame 48.
4. **Watch it shrink, then save it** — played across the
   span, and the file saved with the size memories in it.

The teaching point is that a shrink is a one-way trip in
size, the mirror of the grow: the grow went up and stayed,
a shrink goes down and stays — at frame 24 the thing reads
0.7096 on every side, partway down. The checks read the
real evaluated size at the first and last memories: the
span must run at least 20 frames, and the biggest side's
end ratio must be at most 0.55 of its start, so every side
truly shrank. A probe on Blender 5.3.0 and 4.2.5 before
building showed the size memories across frames 1/48 read
back and interpolate identically on both versions (span
47, ratio 0.4 in the probe; the shipped check reads the
same); a grow read ratio 2.5, a small shrink read 0.8,
and a one-axis-only change read ratio 1.0 — all failing
the bar.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a starting size alone
does not prove the shrink, a grow does not prove it, and
a small shrink (0.8 of size) does not prove it either.

Verified on Blender 5.3.0 AND 4.2.5 at the final v3.27.0
source: the flows battery (all twenty-eight flows plus
the anim_shrink negatives), the interface battery, and
the plain-layer and search batteries all pass on both
versions. Proof picture: demo/anim_shrink_final.png —
the reference build's red thing at frame 48, shrunk to
0.4 of its starting size on every side, resting small
on the ground.
