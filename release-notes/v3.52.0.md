# Blender Buddy v3.52.0 — animation's forty-fifth piece: stepping up

One new guided flow, and nothing else changes. Built and
held locally under the owner's 2026-11-26 release-batching
rule — this is batch bookkeeping, not a separate release;
it ships together with the first batched release.

**Make it step up** sits under "Learn by doing" beside the
modeling, sculpting and first forty-four animation
pieces — Buddy's forty-fifth animation piece, teaching
stepping up, in four steps:

1. **Pick the thing that will step up** — one thing that will
   step up and stay there.
2. **Remember where it starts, on the ground** — a place
   memory at frame 1, its centre no more than 1.3 units up.
3. **Step it up and keep it there** —
   moved forward 1.0 units along X and up 1.0 units along Z remembered at frame 24, and
   the same stepped-up place remembered again at frame 48, never
   travelling sideways the whole way.
4. **Watch it step up, then save** — played across the
   span, and the file saved with the place memories
   in it.

The teaching point is that a step up is the forward
step and the rise and the staying together: the step forward piece
stepped a thing forward along the ground and kept it there, and the float piece
raised a thing straight up and kept it there — a step up
steps forward AND up, one step in both directions together, and stays in the
new higher place, never travelling
sideways and never dipping below where it started, reading places
(0, 0, 0) / (1, 0, 1) / (1, 0, 1) at frames
1/24/48 in the reference build (0.4674 forward and 0.4674 up partway
across at frame 12). The checks sample the real evaluated place
across the span: the span must run at least 20 frames,
the forward displacement from the start place to the end
place must land between 0.7 and 1.3, the rise from the start
height to the end height must land between 0.7 and 1.3, the end
height must land between 0.7 and 1.3, the sideways drift
along Y must stay within 0.5 across all samples, and the
sampled height must never drop more than 0.35 below the start height. A probe on Blender 5.3.0 and 4.2.5
before building showed the place memories at
(0, 0, 0), (1, 0, 1) and (1, 0, 1) across frames
1/24/48 read back and interpolate identically on both
versions (span 47, forward 1.0, sideways drift
0.0, start 0.0, end 1.0, lowest 0.0 in the probe); a float read forward 0.0 with rise 1.5 and end 1.5,
a step forward read forward 2.0 with rise 0.0, a climb straight up read forward 0.0 with rise 3.0, a hop read rise 0.0 with end 0.0, a small step up read forward 0.3 with rise 0.3, a diagonal sidestep-up
read sideways drift 1.0, and a step down read rise -1.0 with end 0.0 — all failing the bar.

Negative cases are in the battery alongside the walk:
a plain scene ticks only step 1, a ground starting
place alone does not prove the step up, a float does not
prove it, a step forward does not prove it, a climb straight up does not prove it, a hop does not prove it, a small step up does not
prove it, a diagonal sidestep-up does not prove it, and a step down does not prove it either.

Verified on Blender 5.3.0 and 4.2.5 at the final
v3.52.0 source: the flows battery (all fifty-three
flows plus the anim_stepup negatives), the interface
battery, and the plain-layer and search batteries all
pass. Proof picture: demo/anim_stepup_final.png — the
reference build's red thing at frame 36, in its
stepped-up place above the ground with its
shadow below.
