# Blender Buddy v3.8.0 — animation's first piece: keyframes

One new guided flow, and nothing else changes.

**Make it move** sits under "Learn by doing" beside the
modeling and sculpting pieces — Buddy's first animation
piece, teaching the one idea all animation is built from,
in five steps:

1. **Pick the thing that will move** — one thing, chosen;
   a fresh box if the scene is empty.
2. **Remember where it starts** — a keyframe at frame 1:
   the thing's place, remembered. The tick reads the
   memory itself, a real key on the thing's location at
   the start.
3. **Move it, and remember again** — a later frame, a
   clear move, a second memory; Blender fills in every
   frame between. The tick reads both memories and the
   real distance travelled between them (at least 20
   frames apart, at least one full pace of travel) —
   keys at nearly the same place do not prove movement.
4. **Give it a turn as well** — facing is remembered the
   same way as place: remembered at the start, turned
   and remembered at the end, the spin filled in
   between. The tick reads the facing memories and the
   real turn between them.
5. **Watch it, then save it** — played back from the
   start, and the file saved with both sets of memories
   still on the thing.

The checks read the animation the way the running
Blender stores it: on 4.2 the keys sit on the action
itself; on 5.x they sit in the keyframe strip's channel
bag, reached through the action's slot. One helper reads
both — probed on Blender 5.3.0 and 4.2.5 before building,
both reading back the same keys — and the travelled
distance and turn are read by putting the play line on
the key frames and reading the thing's real place and
facing there.

Negative cases are in the battery alongside the walk: a
plain thing ticks only step 1, one starting memory alone
ticks neither the moved nor the turned step, and a
second memory at nearly the same place does not prove
travel.

The Start screen's coverage box now names animation's
first piece and still says plainly that it is a first
piece of the craft, not the whole of it; the other
crafts remain untaught.

Verified on Blender 5.3.0 and 4.2.5: the flows battery
(all nine flows walked end to end, anim_move included,
plus its three negative cases and the sculpting
negatives), the interface battery (including the
coverage box), and the plain-layer and search
batteries. The 4.2.5 pass owed for v3.4.0–v3.7.0 was
also run this cycle — the flows, interface, plain-layer
and search batteries pass on 4.2.5 at the v3.8.0 source,
which contains those versions' flows unchanged. The
full parallel battery (test_tour) remains owed on an
unloaded machine, as recorded in the lane queue.
